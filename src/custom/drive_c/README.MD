# The purpose of this directory is invoking a compile run in a DOSBox

* BORLANDC - old directory of Borland C++ 3.1 compiler (may be removed in future)
* BCC31	- here should be installed YOUR OWN copy of the Borland C++ 3.1 compiler
* BCC30	- ...
* BCC20	- ...
* src		- here will be the sources of the program you want to compile
* compile.conf	- configuration file for DOSBox (may be removed in future)
			(set environment, mount c, chdir to src, run compile.bat, exit)
* bcc31.conf - here should be the new config for DOSBox with BCC 3.1
* bcc30.conf - here should be the new config for DOSBox with BCC 3.0
* bcc20.conf - here should be the new config for DOSBox with BCC 2.0
